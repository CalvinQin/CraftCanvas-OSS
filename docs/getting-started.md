# 快速开始

按 README 安装并启动本地前后端。在 `/account` 注册邮箱账号，然后进入 `/workflow`。

1. 选择「图片处理与交付」模板。
2. 上传一张无敏感信息的商品图。
3. 选择旋转节点，设置方向，点击「运行工作流」。
4. 检查输出结果，下载图片或导出完整 JSON。
5. 等待保存状态显示成功后再离开。遇到版本冲突，先备份再加载云端。

这个流程不调用模型。尝试 AI 节点前，由部署者配置有效的服务端密钥，确认额度与可能的费用。新用户不会自动获得管理员权限。

进一步阅读：[工作流](workflows.md) · [自托管](self-hosting.md) · [架构](../Design.md)。
