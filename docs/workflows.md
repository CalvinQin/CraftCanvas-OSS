# 可视化节点工作流

六类节点：图片输入、提示词、模型生图、白底去背景、旋转与翻转、图片输出。最多 60 个节点、120 条连线，单个生图节点最多 16 张参考图；每个账号最多保存 30 条工作流。

从输出端口连接同类型输入，或在节点设置中选择目标。系统拒绝循环、重复连接和类型不匹配。运行整个流程或运行到指定节点，依赖完成后下游才开始；最多两个就绪步骤并行。

修改影响结果的参数时，会重置当前节点与下游结果。改名和拖动位置不会使结果失效。某个分支失败后，其他独立分支可以继续。成功且未修改的结果可复用。

执行需保持页面打开。停止阻止新步骤启动，不撤销已提交请求；手动重试可能再次产生模型费用。页面关闭后未保存的修改不能保证恢复。

工作流 JSON 包含节点、连线、输入图和成功结果。备份可重新导入；分享前检查私人图片。保存冲突请先备份本地版本，再加载云端最新状态。

白底去背景是浏览器中的颜色处理，并非通用语义分割。复杂背景或白色主体可能需要进一步调整。
